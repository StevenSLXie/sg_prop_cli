# Area And Bedroom Heuristics

URA private sale transactions include `area_sqm`, but not bedroom count.

Use these area bands only as rough hints, never as proof:

| Layout | Rough Area Hint |
|---|---:|
| 1 bedder | 40-60 sqm |
| 2 bedder | 55-80 sqm |
| 3 bedder compact | 75-95 sqm |
| 3 bedder regular | 90-120 sqm |
| 4 bedder | 115-160 sqm |

Notes:

- Project layouts vary widely.
- Older projects may have larger units.
- Newer projects may have compact bedroom layouts.
- EC and condo unit layouts differ.
- Always verify bedroom count with project floor plans or reliable listing/project metadata before making a confident statement.
