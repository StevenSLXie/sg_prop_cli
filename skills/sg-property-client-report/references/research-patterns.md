# Research Patterns

Use these patterns to make the report feel like real property advisory work rather than a data dump.

## Stacked-Style Depth Cues

Public Stacked Homes reviews commonly combine:

- project facts and full rundown
- insider-tour / living experience
- location and access
- unit mix and layout notes
- site plan and stack analysis
- facilities and maintenance/lifestyle implications
- pricing analysis against nearby alternatives
- who should like it and who should avoid it

Do not copy wording. Use the structure as a checklist for report completeness.

Useful public references:

- Stacked Homes editorial review examples: https://stackedhomes.com/
- Stacked Homes condo directory example: https://directory.stackedhomes.com/condo/dleedon/

## First-Principles Client Questions

Answer these before recommending:

- Can the client afford a unit that actually exists in the project/area?
- Is the layout suitable for the client, not just within budget?
- Is there enough resale/rental liquidity for exit or leasing?
- Is the current asking level supported by recent transactions?
- Are peers materially better for the same budget?
- What hidden trade-off explains a cheaper PSF?
- What must be verified before viewing or offering?

## Recommendation Discipline

Use a balanced frame:

- buy/shortlist/watch/pass
- confidence level
- evidence that supports the conclusion
- evidence that weakens the conclusion
- bid discipline or next-step diligence

Avoid generic praise. If the evidence is mixed, say it is mixed.
