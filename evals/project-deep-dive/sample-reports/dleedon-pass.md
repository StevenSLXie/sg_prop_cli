## Recommendation

D'LEEDON is worth shortlisting if the buyer values D10 location and accepts leasehold tenure. The main due diligence is layout-specific liquidity: verify how many 3-bedroom units exist, how often that exact layout trades, and whether current asking PSF is above recent transacted PSF. If active listings are materially above the recent transaction range, use the transaction median as bid discipline rather than chasing asking prices.
