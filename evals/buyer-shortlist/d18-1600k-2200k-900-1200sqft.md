# Eval Case: D18 Budget And Size Shortlist

## Prompt

```text
Look at D18, 1.6-2.2m budget, 900-1200 sqft. What condo projects should I shortlist? I care about practical options, not a long list.
```

## Expected Behavior

- Convert 900-1200 sqft to about 84-111 sqm.
- Use `find_private_residential_sale_comparables` first with:
  - `district: "18"`
  - `min_price: 1600000`
  - `max_price: 2200000`
  - `min_area_sqm` around `84`
  - `max_area_sqm` around `111`
  - `output_mode: "summary"`
- Use `project_summaries` to build the first shortlist.
- Avoid fetching rows for every project.
- Mention sample size and transaction window.
- Explain that bedroom count is not in URA sale rows and needs project metadata/floorplan verification.
- Produce a shortlist table and 3-5 recommended next-step projects.

## Failure Modes

- Treating 900-1200 sqft as sqm.
- Claiming exact 3-bedder status from URA rows alone.
- Dumping raw rows instead of summarizing.
- Ignoring sample size.
- Making valuation claims.
